# UI screenshots

Screenshots of the implemented Amwal web application (https://amwal.id) used as visual evidence for the paper.

**Capture method.** Automated browser run (Chromium, device emulation) on 16 October 2026 against a local production build populated with a seeded demonstration dataset and a simulated payment gateway. Pixel density is 2×: laptop viewport 1440 × 900 CSS px (2880 px wide), phone viewport 390 × 844 CSS px (780 px wide). Pages are captured at full length. The images are emulated renderings, not captures from physical devices; names, amounts and order numbers are demonstration data.
